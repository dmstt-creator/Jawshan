# دعای جوشن کبیر — خوانش، ترجمه و حفظ

۱۰۰ بند و ۱۰۰۰ اسم با صدای میثم مطیعی، ترجمهٔ فارسی، جستجو، و تکرار پیش‌رونده برای حفظ. صوت، فونت‌ها و متن داخل خود `index.html` است و برنامه بدون اینترنت هم کار می‌کند. با فایل‌های کنارش، به‌صورت اپ (PWA) روی گوشی نصب می‌شود.

## فایل‌ها

| فایل | کار |
|---|---|
| `index.html` | خود برنامه |
| `manifest.webmanifest` | نام، رنگ و آیکون اپ |
| `sw.js` | کار بدون اینترنت پس از نصب |
| `icon-*.png`، `apple-touch-icon.png` | آیکون‌ها |

## انتشار در GitHub Pages

1. در github.com یک مخزن تازه و Public بسازید، مثلاً `jawshan`.
2. «Add file» ← «Upload files»: همهٔ فایل‌های بالا را با هم در ریشهٔ مخزن بارگذاری کنید.
3. «Settings» ← «Pages» ← Source: «Deploy from a branch»، شاخهٔ `main` و پوشهٔ `/ (root)` ← Save.
4. چند دقیقه بعد برنامه در `https://USERNAME.github.io/jawshan/` باز می‌شود.

## نصب به‌صورت اپ

- **اندروید (کروم):** در صفحهٔ اول «📲 نصب به‌صورت اپ» را بزنید، یا از منوی ⋮ «نصب برنامه».
- **آیفون (سافاری):** دکمهٔ اشتراک ← «Add to Home Screen».
- **فایل APK اندروید:** نشانی گیت‌هاب را در pwabuilder.com بدهید و بستهٔ اندروید را بگیرید.

## به‌روزرسانی

`index.html` تازه را جایگزین کنید و در `sw.js` مقدار `VERSION` را یکی بالا ببرید (مثلاً `jawshan-v2`). اطلاعات ذخیره‌شدهٔ کاربران (تنظیمات، جای خوانش، شمارش) باقی می‌ماند.
